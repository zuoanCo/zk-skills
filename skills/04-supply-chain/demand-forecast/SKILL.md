# demand-forecast · 销量预测

预测明天会卖多少，今天该备多少货。

## 用途

- 预测 SKU 未来销量
- 支持 7 天、30 天、90 天多时间窗口
- 识别季节性、促销、趋势影响
- 为补货和生产计划提供量化依据

## 触发场景

- 每周补货会议前
- 大促备货规划
- 新品上架后预测首月销量
- 发现销量异常波动

## 输入

- 历史销售数据（至少 3 个月）
- SKU 信息
- 价格变动记录
- 促销活动日历
- 市场趋势信号（可选）
- 季节性因子

## 输出

```markdown
## 销量预测报告

### 预测概览
| SKU | 未来 7 天 | 未来 30 天 | 未来 90 天 | 置信区间 |
|-----|----------|-----------|-----------|---------|
| A   | 120      | 520       | 1,650     | ±15%    |

### 趋势分析
### 季节性影响
### 关键假设
### 风险提示
```

## 预测方法

- **基线预测**：移动平均 / 指数平滑
- **趋势预测**：线性回归 / Holt-Winters
- **季节性**：季节性分解
- **外部变量**：价格、促销、广告 spend、市场热度
- **新品预测**：类比相似品 launch 曲线

## 工作流

1. **数据清洗**：去异常值、补齐缺失。
2. **特征工程**：时间特征、促销标记、价格、广告。
3. **模型选择**：根据数据量选择合适模型。
4. **预测生成**：输出点预测 + 置信区间。
5. **结果解释**：说明关键假设和不确定性。
6. **反馈校准**：对比实际销量，持续优化。

## 调用关系

**被调用**：task-planning、inventory-analysis、replenishment

**调用**：data-analysis、advertising-analysis、market-research

## 依赖工具 / Memory

- Tool: Python / SQL / BI 工具
- Memory: 历史预测准确率、季节性因子库

## 边界与限制

- 预测不是预言，需标注置信区间
- 新品、突发事件预测难度大
- 需持续用实际数据校准模型

## 示例

输入：某宠物饮水机过去 6 个月销售数据
输出：未来 30 天预测销量 520，受夏季宠物饮水需求上升影响，建议提前备货
