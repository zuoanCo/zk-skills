# fulfillment-management · 履约管理

## 用途
- 跟踪订单履约状态
- 识别异常订单（延迟、丢件、退货）
- 协调仓库和物流
- 提升签收率和客户满意度

## 触发场景
- 每日履约监控
- 客户投诉物流问题
- 异常订单预警
- 物流商考核

## 输入
- 订单数据
- 仓库出库数据
- 物流追踪号
- 签收状态
- 退货数据

## 输出
```markdown
## 履约监控报告

### 今日订单概况
### 在途订单
### 异常订单
### 签收率
### 物流商表现
### 建议动作
```

## 工作流
1. **拉取订单**：从 Odoo / 电商平台
2. **跟踪物流状态**：根据追踪号同步
3. **识别异常**：超时未更新、丢件、退回
4. **预警升级**：通知客服或仓库
5. **物流商考核**：时效、签收率、异常率
6. **输出报告**：每日履约看板

## 调用关系
**被调用**：customer-support、workflow-automation

**调用**：odoo-integration、ecommerce-api

## 依赖工具 / Memory
- Tool: 物流追踪 API、电商平台 API
- Memory: 物流商表现、异常处理案例

## 边界与限制
- 不直接联系物流商或客户
- 只输出异常预警和处理建议
- 涉及赔偿需人工处理

## 示例
输出：今日 5 单物流 5 天未更新，建议联系物流商；USPS 签收率 96%，FedEx 98%
