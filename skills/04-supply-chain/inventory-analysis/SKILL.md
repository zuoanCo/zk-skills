# inventory-analysis · 库存分析

让库存不积压、不断货、资金占用最小化。

## 用途

- 监控库存周转率
- 识别缺货风险 SKU
- 发现呆滞和滞销库存
- 分析库龄结构
- 为补货和清仓决策提供数据

## 触发场景

- 每周 / 每月库存盘点后
- 发现销量异常波动
- 大促前备货规划
- 现金流紧张需要去库存

## 输入

- Odoo Inventory 数据
- 销售数据（7 / 30 / 90 天）
- 在途库存
- 安全库存设定
- 仓库分布

## 输出

```markdown
## 库存分析报告

### 整体指标
- 总库存金额
- 库存周转天数
- 可售天数
- 缺货 SKU 数
- 呆滞 SKU 数

### SKU 健康度分类
| SKU | 库存量 | 近 30 天销量 | 周转天数 | 状态 | 建议 |
|-----|--------|-------------|---------|------|------|

### 缺货风险
### 呆滞库存
### 优化建议
```

## SKU 健康度分类

| 状态 | 定义 | 建议 |
|------|------|------|
| 健康 | 周转天数在目标区间 | 维持 |
| 缺货风险 | 库存 < 安全库存 | 紧急补货 |
| 滞销 | 近 30 天销量极低 | 清仓 / 降价 |
| 呆滞 | 库龄 > 180 天 | 促销 / 下架 |

## 工作流

1. **拉取数据**：从 Odoo Inventory 读取库存、在途、库龄。
2. **合并销售数据**：按 SKU 计算销量和周转。
3. **分类健康度**：健康 / 缺货风险 / 滞销 / 呆滞。
4. **风险排序**：按金额和风险优先级排序。
5. **输出建议**：补货、促销、清仓、调仓。

## 调用关系

## 依赖工具 / Memory

- Tool: Odoo Inventory API
- Memory: 历史库存周转基准、安全库存策略

## 边界与限制

- 只分析已有数据，不自动创建采购单
- 数据延迟需标注
- 补货建议需结合 demand-forecast 共同判断

## 示例

输入：本周 Odoo 库存数据
输出：3 个 SKU 缺货风险、5 个 SKU 呆滞、建议对 SKU-A 紧急补货，SKU-B 降价清仓
