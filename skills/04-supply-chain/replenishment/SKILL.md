# replenishment · 补货策略

## 用途
- 自动计算安全库存
- 根据预测生成补货建议
- 平衡缺货风险和库存积压
- 输出可执行的补货计划

## 触发场景
- 每周补货会议
- 库存预警
- 大促备货
- 新品首单后补货

## 输入
- 当前库存
- 在途库存
- 销量预测
- 采购周期
- 安全库存目标
- 仓库分布

## 输出
```markdown
## 补货建议

### 需要补货的 SKU
| SKU | 建议补货量 | 目标仓库 | 期望到仓时间 |

### 补货总量
### 资金占用预估
### 风险说明
```

## 工作流
1. **计算日均销量**：基于 demand-forecast
2. **设定安全库存**：通常 14-30 天销量
3. **计算补货点**：安全库存 + 采购周期 × 日均销量
4. **计算补货量**：目标库存 - 现有库存 - 在途库存
5. **输出建议**：按优先级排序
6. **生成采购草稿**：连接 purchase-management

## 调用关系
**被调用**：inventory-analysis、demand-forecast

**调用**：purchase-management、odoo-integration

## 依赖工具 / Memory
- Tool: Odoo Inventory、预测模型
- Memory: 采购周期、安全库存策略

## 边界与限制
- 只输出建议，不自动下单
- 季节性、促销期需人工调整
- 新供应商首单需额外缓冲

## 示例
输出：WP-001 建议补货 600 台，目标美西仓，预计资金占用 $5,220
