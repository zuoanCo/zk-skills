# logistics-optimization · 物流优化

## 用途
- 比较不同物流方式成本与时效
- 优化头程和尾程物流
- 规划海外仓布局
- 降低物流成本

## 触发场景
- 新品出货前选择物流
- 物流成本上涨
- 旺季备货需要加急
- 评估新仓库布局

## 输入
- 货物信息（重量、体积、货值）
- 起运地和目的地
- 时效要求
- 预算约束
- 各物流商报价

## 输出
```markdown
## 物流优化方案

### 方案对比
| 方式 | 时效 | 成本 | 适用场景 |

### 推荐方案
### 海外仓建议
### 成本优化空间
```

## 工作流
1. **收集报价**：海运、空运、铁路、快递
2. **计算总成本**：运费 + 关税 + 保险 + 仓储
3. **评估时效**：满足不同 SKU 需求
4. **风险分析**：延误、查验、损耗
5. **输出方案**：常规 / 加急 / 经济
6. **海外仓规划**：库存分布建议

## 调用关系
**被调用**：quotation-analysis、replenishment

**调用**：cost-analysis、data-analysis

## 依赖工具 / Memory
- Tool: 物流商 API、运费计算器
- Memory: 历史物流时效、查验率

## 边界与限制
- 不直接预订物流
- 报价以物流商最新确认为准
- 危险品需特殊处理

## 示例
输出：2000 台饮水机推荐美森快船（18 天，$1.1/件），比空运节省 60%
