# pricing-strategy · 定价策略

## 用途
- 分析成本结构
- 研究竞品价格带
- 应用心理定价策略
- 制定多平台价格策略

## 触发场景
- 新品上架定价
- 竞品降价需要应对
- 利润下滑需要调价
- 大促折扣策略制定

## 输入
- 全成本数据
- 竞品价格
- 目标利润率
- 品牌定位
- 平台费用

## 输出
```markdown
## 定价策略方案

### 成本结构
### 竞品价格带
### 建议售价
### 心理定价点
### 促销底价
### 多平台价格建议
```

## 工作流
1. **成本核算**：采购、物流、平台、广告、税费
2. **竞品价格扫描**：高、中、低价格带
3. **确定价格锚点**：避开红海、匹配定位
4. **心理定价**：$39.99 vs $40
5. **测试与迭代**：A/B 测试价格敏感度
6. **输出策略**：日常价、促销价、底线价

## 调用关系
**被调用**：product-selection、amazon-operation

**调用**：profitability-analysis、competitor-analysis、cost-analysis

## 依赖工具 / Memory
- Tool: 价格监控工具
- Memory: 历史价格测试、促销效果

## 边界与限制
- 不自动修改平台售价
- 定价需考虑品牌长期定位
- 低价竞争需谨慎

## 示例
输出：建议定价 $39.99（竞品中位 $35-$45，心理价位 $39-$49），促销底价 $34.99
