# product-positioning · 产品定位

把"卖货"变成"卖解决方案"。

## 用途

- 生成产品核心故事和定位语
- 定义目标用户画像和使用场景
- 提炼差异化卖点（USP）
- 将功能卖点翻译为情绪价值
- 为 Listing、广告、内容提供统一口径

## 触发场景

- 选品通过后需要确定定位
- Listing 文案缺乏打动人心的卖点
- 广告转化低，需要重新提炼卖点
- 品牌升级或产品线扩展

## 输入

- 产品基础信息（功能、规格、价格）
- 目标市场
- 用户洞察（痛点、购买动机）
- 竞品卖点和差评
- 品牌调性（可选）

## 输出

```markdown
## 产品定位方案

### 产品故事
{一段 100-200 字的品牌叙事}

### 目标用户
- 人群画像
- 核心痛点
- 购买动机
- 使用场景

### 差异化卖点
1. {功能卖点} → {用户收益} → {情绪价值}
2. ...

### 定位语
- 主标题
- 副标题
- 30 秒电梯演讲

### 应用口径
- Listing 标题方向
- 五点描述方向
- 广告文案方向
```

## 工作流

1. **用户洞察输入**：痛点、动机、场景。
2. **竞品对照**：找到差异化空间。
3. **价值分层**：
   - 功能价值（是什么）
   - 收益价值（能帮我做什么）
   - 情绪价值（让我感觉如何）
4. **生成故事和卖点**：
   - 普通版：狗狗饮水机
   - 升级版：给独居宠物主人的智能健康饮水方案
5. **输出定位资产**：故事、用户画像、USP、口径。

## 调用关系

**被调用**：task-planning、product-selection

**调用**：customer-insight、competitor-analysis、listing-writing

## 依赖工具 / Memory

- Memory: 品牌话术库、历史成功定位案例
- Tool: 飞书文档（输出定位方案）

## 边界与限制

- 定位需基于真实用户需求，不编造故事
- 需与市场、法务确认不夸大宣传
- 定位语需本地化，不能直译

## 示例

输入：宠物智能饮水机
输出：
- 产品故事：每一位早出晚归的宠物主人都希望毛孩子喝上干净活水...
- 目标用户：25-40 岁都市独居宠物主人
- USP：静音水泵 + 三重过滤 + App 缺水提醒
- 定位语：不在家，也能给它刚好的新鲜
