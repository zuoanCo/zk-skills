# memory-manager · 经验管理

## 用途
- 保存 Agent 执行经验
- 支持经验检索和复用
- 管理记忆生命周期
- 为 Skill 改进提供数据

## 触发场景
- 任务完成后
- 需要查找历史经验
- 记忆过多需要清理
- Skill 改进时

## 输入
- 任务结果
- 执行日志
- 成功/失败标记
- 经验内容

## 输出
```markdown
## 记忆管理报告

### 新增记忆
### 更新记忆
### 检索结果
### 记忆质量评估
```

## 工作流
1. **提取经验**：从任务中提炼有价值信息
2. **结构化存储**：标签、领域、类型
3. **索引管理**：便于检索
4. **定期清理**：删除过时记忆
5. **检索复用**：新任务匹配历史经验
6. **反馈更新**：根据效果更新记忆

## 调用关系
**被调用**：knowledge-management、skill-improvement

**调用**：knowledge-curator

## 依赖工具 / Memory
- Tool: 记忆存储（文件/向量库）
- Memory: 记忆索引

## 边界与限制
- 不保存敏感信息
- 记忆需标注置信度
- 定期验证记忆有效性

## 示例
输出：将 'TikTok 宠物饮水机场景视频 CTR 高' 保存为记忆，供后续 content-agent 调用
