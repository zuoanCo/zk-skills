# knowledge-curator · 知识整理

## 用途
- 整理碎片化知识
- 建立知识结构
- 维护知识库索引
- 提升知识检索效率

## 触发场景
- 知识库内容增多
- 需要更新知识架构
- 检索效率低
- 需要建立知识体系

## 输入
- 知识条目
- 分类体系
- 用户需求
- 使用数据

## 输出
```markdown
## 知识整理报告

### 知识分类
### 索引更新
### 关联关系
### 缺失知识
### 推荐补充
```

## 工作流
1. **收集知识**：经验、SOP、案例、模板
2. **分类打标签**：领域、类型、场景
3. **建立关联**：相似、因果、依赖
4. **更新索引**：目录、关键词
5. **清理冗余**：合并重复、删除过时
6. **输出地图**：知识图谱或目录

## 调用关系
**被调用**：knowledge-management、memory-manager

**调用**：无

## 依赖工具 / Memory
- Tool: 知识库、向量检索
- Memory: 知识分类体系

## 边界与限制
- 不删除未经确认的知识
- 分类需符合业务逻辑
- 保持知识更新

## 示例
输出：整理出 5 大知识领域、32 个子类，建立经验-SOP-模板三级结构
