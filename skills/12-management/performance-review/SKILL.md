# performance-review · 绩效分析

## 用途
- 量化团队和 Agent 产出
- 识别绩效瓶颈
- 支持绩效评估
- 输出改进计划

## 触发场景
- 月度/季度绩效评估
- 团队复盘
- Agent 效果评估
- 需要优化资源配置

## 输入
- 任务完成数据
- KPI 定义
- 目标值
- 历史绩效

## 输出
```markdown
## 绩效分析报告

### KPI 完成情况
### 同比/环比
### 亮点与不足
### 瓶颈分析
### 改进建议
### 下阶段目标
```

## 工作流
1. **确定 KPI**：与目标对齐
2. **收集数据**：任务、产出、质量、时效
3. **计算达成率**：实际 vs 目标
4. **多维分析**：人、Skill、项目
5. **识别问题**：低效率、高错误、瓶颈
6. **输出建议**：培训、流程优化、资源调整

## 调用关系
**被调用**：CEO Agent、task-followup

**调用**：data-analysis、report-generation

## 依赖工具 / Memory
- Tool: 任务系统、数据分析工具
- Memory: KPI 定义、历史绩效

## 边界与限制
- 绩效分析需公平透明
- 不用于惩罚，用于改进
- 指标需与目标强相关

## 示例
输出：market-agent 本月完成 8 份调研报告，平均交付时间 2.5 天，准确率 92%，建议优化数据清洗流程
