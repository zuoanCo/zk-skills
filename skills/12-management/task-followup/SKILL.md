# task-followup · 任务跟踪

## 用途
- 跟踪任务执行情况
- 提醒逾期任务
- 汇总项目进度
- 推动任务闭环

## 触发场景
- 每日任务检查
- 项目进度会议
- 任务逾期预警
- 需要生成进度报告

## 输入
- 任务列表
- 负责人
- 截止时间
- 当前进度
- 飞书任务数据

## 输出
```markdown
## 任务跟踪报告

### 总体进度
### 逾期任务
### 本周到期
### 已完成
### 阻塞项
### 建议行动
```

## 工作流
1. **拉取任务**：从飞书或任务系统
2. **分类状态**：未开始 / 进行中 / 已完成 / 逾期
3. **识别阻塞**：任务依赖、资源问题
4. **提醒预警**：逾期前 1-3 天提醒
5. **输出报告**：进度、风险、建议
6. **推动闭环**：跟进逾期任务

## 调用关系
**被调用**：CEO Agent、task-planning

**调用**：feishu-automation、meeting-summary

## 依赖工具 / Memory
- Tool: 飞书任务 API
- Memory: 历史任务完成情况

## 边界与限制
- 不替负责人完成任务
- 提醒需适度，避免骚扰
- 进度以负责人更新为准

## 示例
输出：本周 12 个任务中 2 个逾期，3 个今日到期，已自动发送提醒给负责人
