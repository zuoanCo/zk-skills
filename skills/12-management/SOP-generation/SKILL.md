# SOP-generation · 流程生成

## 用途
- 将经验沉淀为 SOP
- 规范操作流程
- 降低对个人的依赖
- 支持新人培训

## 触发场景
- 完成重要任务后复盘
- 发现流程混乱
- 新人入职培训
- 需要标准化操作

## 输入
- 任务执行记录
- 成功经验
- 失败案例
- 相关 Skill 文档

## 输出
```markdown
## SOP：{流程名称}

### 目的
### 适用范围
### 角色与职责
### 流程步骤
### 验收标准
### 常见问题
### 相关模板
```

## 工作流
1. **收集素材**：执行记录、案例、文档
2. **梳理流程**：按时间线或决策点
3. **定义角色**：谁做什么
4. **明确标准**：输入、输出、验收
5. **输出 SOP**：Markdown 格式
6. **评审发布**：相关岗位确认
7. **持续更新**：根据执行反馈优化

## 调用关系
**被调用**：knowledge-management、skill-improvement

**调用**：knowledge-management、report-generation

## 依赖工具 / Memory
- Tool: 飞书文档、知识库
- Memory: 最佳实践、失败案例

## 边界与限制
- SOP 是指导不是枷锁
- 需定期评审更新
- 不替代人工判断

## 示例
输出：《Amazon PPC 新品上架 SOP》，包含 12 步操作流程、验收标准和常见错误
