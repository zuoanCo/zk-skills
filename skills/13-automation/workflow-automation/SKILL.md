# workflow-automation · 自动流程

## 用途
- 串联多个 Skill 和系统
- 实现业务流程自动化
- 减少重复人工操作
- 提高响应速度

## 触发场景
- 需要自动化某条业务流程
- 多个系统需要协同
- 人工操作重复且规则明确
- 需要实时响应

## 输入
- 流程定义
- 触发条件
- 涉及系统
- 异常处理规则

## 输出
```markdown
## 自动化流程方案

### 流程图
### 触发条件
### 执行步骤
### 异常处理
### 监控告警
```

## 工作流
1. **梳理流程**：订单履约、补货、客服等
2. **定义触发**：定时、事件、阈值
3. **编排步骤**：调用各 Skill / API
4. **设置分支**：正常 / 异常 / 人工介入
5. **测试验证**：沙盒环境跑通
6. **上线监控**：日志、告警、复盘

## 调用关系
**被调用**：CEO Agent、all operational Skills

**调用**：odoo-integration、ecommerce-api、feishu-automation

## 依赖工具 / Memory
- Tool: 工作流引擎 / 脚本
- Memory: 流程模板、异常案例

## 边界与限制
- 关键决策点保留人工确认
- 不处理高价值或高风险自动写操作
- 流程变更需测试

## 示例
输出：订单履约自动化流程 - 订单进入 → 同步 Odoo → 扣减库存 → 推送到仓库 → 获取追踪号 → 通知客服跟进
