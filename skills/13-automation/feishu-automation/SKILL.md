# feishu-automation · 飞书自动化

## 用途
- 发送通知和告警
- 创建审批流
- 写入飞书表格
- 同步任务和会议纪要

## 触发场景
- 需要推送业务通知
- 自动化审批
- 数据同步到飞书
- 任务提醒

## 输入
- 飞书配置
- 消息内容
- 接收人
- 表格/文档 ID

## 输出
```markdown
## 飞书自动化结果

### 操作类型
### 目标对象
### 状态
### 错误信息
```

## 工作流
1. **配置连接**：飞书 app_id、app_secret
2. **选择操作**：消息、审批、表格、文档
3. **组装数据**：按 API 格式
4. **执行操作**：调用飞书 API
5. **处理异常**：重试、告警
6. **记录日志**：便于审计

## 调用关系
**被调用**：workflow-automation、report-generation、task-followup

**调用**：无

## 依赖工具 / Memory
- Tool: 飞书开放平台 API
- Memory: 飞书配置、常用群聊/文档

## 边界与限制
- 不发送垃圾消息
- 敏感审批需人工复核
- API 调用需控制频率

## 示例
输出：每日 8:30 自动推送经营看板到飞书群，包含 GMV、利润、库存、广告 4 个核心指标
