# anomaly-detection · 异常检测

## 用途
- 监控关键指标异常
- 及时发现销量、广告、库存异常
- 减少人工监控成本
- 支持快速响应

## 触发场景
- 每日自动监控
- 关键指标波动
- 建立告警体系
- 复盘异常事件

## 输入
- 历史指标数据
- 监控指标列表
- 异常阈值
- 时间窗口

## 输出
```markdown
## 异常检测报告

### 异常指标
### 异常时间
### 异常程度
### 可能原因
### 建议动作
### 相关影响
```

## 工作流
1. **定义指标**：销量、广告、库存、利润
2. **建立基线**：历史均值、标准差、趋势
3. **选择算法**：统计阈值、同比环比、时序模型
4. **检测异常**：超出阈值或偏离趋势
5. **根因提示**：关联指标分析
6. **推送告警**：飞书 / 邮件通知

## 调用关系
**被调用**：business-dashboard、workflow-automation

**调用**：data-analysis、feishu-automation

## 依赖工具 / Memory
- Tool: Python、时序模型
- Memory: 历史异常案例、阈值配置

## 边界与限制
- 异常可能是正常波动，需人工判断
- 阈值需根据业务调整
- 不自动采取业务动作

## 示例
输出：WP-001 今日销量较 7 日均值下降 65%，同时广告 spend 正常，疑似库存断货或差评影响
