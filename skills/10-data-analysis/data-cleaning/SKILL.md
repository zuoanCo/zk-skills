# data-cleaning · 数据清洗

## 用途
- 处理缺失值、异常值
- 统一数据格式
- 去重和合并
- 建立数据质量规则

## 触发场景
- 数据分析前
- 发现数据异常
- 建立数据管道
- 对接新数据源

## 输入
- 原始数据
- 数据字典
- 清洗规则
- 质量要求

## 输出
```markdown
## 数据清洗报告

### 数据概况
### 质量问题
### 清洗规则
### 清洗后数据
### 质量评分
```

## 工作流
1. **数据探查**：分布、缺失、异常
2. **制定规则**：填充、删除、转换、校验
3. **执行清洗**：去重、格式统一、异常处理
4. **质量验证**：完整性、一致性、准确性
5. **输出报告**：问题清单和清洗结果
6. **建立监控**：持续数据质量检查

## 调用关系
**被调用**：data-analysis、business-dashboard、demand-forecast

**调用**：odoo-integration、ecommerce-api

## 依赖工具 / Memory
- Tool: Python pandas / SQL
- Memory: 数据字典、清洗规则库

## 边界与限制
- 不删除原始数据
- 清洗规则需记录
- 对业务有影响的处理需确认

## 示例
输出：清洗 50,000 条订单，修复 1,200 个缺失 SKU，删除 45 条重复记录，标记 230 个异常金额
