# data-analysis · 数据分析

## 用途
- 回答复杂业务问题
- 进行多维度分析
- 发现数据规律和异常
- 输出可行动洞察

## 触发场景
- 业务问题需要数据支撑
- 需要深度分析
- 建立分析模型
- 数据驱动决策

## 输入
- 清洗后的数据
- 分析目标
- 假设和问题
- 工具偏好

## 输出
```markdown
## 数据分析报告

### 分析目标
### 数据说明
### 分析方法
### 关键发现
### 业务建议
### 附录：代码 / 查询
```

## 工作流
1. **明确问题**：业务问题转化为数据问题
2. **提取数据**：SQL、API、文件
3. **探索分析**：描述统计、可视化
4. **建模分析**：回归、聚类、时序
5. **验证假设**：A/B 测试、显著性
6. **输出洞察**：结论和建议

## 调用关系
**被调用**：所有需要数据分析的 Skill

**调用**：data-cleaning、business-dashboard

## 依赖工具 / Memory
- Tool: SQL、Python、Jupyter、BI 工具
- Memory: 分析模板、常用查询

## 边界与限制
- 分析结果受数据质量限制
- 相关性不等于因果性
- 复杂模型需验证假设

## 示例
输出：分析发现广告 Spend 与销量存在 3 天滞后，建议调整预算分配节奏，周末前置投放
