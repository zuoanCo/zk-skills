# cost-analysis · 成本分析

## 用途
- 拆解全链路成本
- 识别成本异常
- 分析降本空间
- 为定价和利润分析提供基础

## 触发场景
- 利润下滑需要分析成本
- 供应商报价对比
- 物流费用上涨
- 年度成本预算

## 输入
- 采购成本
- 物流账单
- 平台费用
- 广告 spend
- 税费
- 其他运营费用

## 输出
```markdown
## 成本分析报告

### 总成本结构
### 各 SKU 成本分布
### 异常成本项
### 降本建议
### 敏感性分析
```

## 工作流
1. **归集成本**：按类目、SKU、时间归集
2. **分类统计**：采购、物流、平台、广告、税费
3. **对比分析**：环比、同比、预算对比
4. **识别异常**：超预算、单价异常、损耗
5. **输出建议**：议价、换物流、优化包装
6. **敏感性分析**：成本变动对利润影响

## 调用关系
**被调用**：profitability-analysis、quotation-analysis

**调用**：odoo-integration、data-analysis

## 依赖工具 / Memory
- Tool: Odoo Accounting、账单数据
- Memory: 历史成本基准、供应商价格库

## 边界与限制
- 成本数据需准确归集
- 间接费用分摊需约定规则
- 降本建议需考虑质量风险

## 示例
输出：物流成本占比从 12% 升至 16%，建议换海运联盟，预计节省 8% 头程费用
