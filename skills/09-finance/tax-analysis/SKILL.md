# tax-analysis · 税务分析

## 用途
- 分析目标市场税务要求
- 计算销售税 / VAT / GST
- 识别税务风险
- 辅助税务合规

## 触发场景
- 进入新市场
- 税务合规审查
- 利润分析需要扣税
- 平台税务政策变化

## 输入
- 目标市场
- 销售额
- 产品类别
- 仓储地点
- 公司注册地

## 输出
```markdown
## 税务分析报告\n\n### 适用税种\n### 税率\n### 税务义务\n### 税费计算\n### 合规建议\n### 风险提示\n```

## 工作流
1. **识别税种**：销售税、VAT、GST、进口税
2. **确定税率**：按国家和州/省
3. **判断纳税义务**：经济联结（nexus）
4. **计算税费影响**：对利润的影响
5. **合规建议**：注册、申报、代扣
6. **风险提示**：逾期、漏报、误算

## 调用关系
**被调用**：profitability-analysis、market-research

**调用**：compliance-check、accounting-assistant

## 依赖工具 / Memory
- Tool: 税务数据库、平台税务报告
- Memory: 各国税务规则、申报日历

## 边界与限制
- 不替代专业税务顾问
- 税务规则变化快，需定期更新
- 重大税务决策需确认当地法规

## 示例
输出：美国销售需关注各州经济联结，预计销售税占收入 6-10%，建议注册 Avalara 或 TaxJar 自动计算
