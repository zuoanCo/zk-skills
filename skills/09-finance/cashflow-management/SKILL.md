# cashflow-management · 现金流预测

## 用途
- 预测未来现金流
- 预警资金缺口
- 优化付款节奏
- 支持采购和库存决策

## 触发场景
- 月度财务规划
- 大促备货前
- 现金流紧张
- 需要融资或贷款

## 输入
- 销售预测
- 采购计划
- 费用预算
- 应收账款
- 应付账款
- 现金余额

## 输出
```markdown
## 现金流预测报告

### 当前现金余额
### 未来 13 周现金流
### 资金缺口预警
### 建议行动
### 敏感性分析
```

## 工作流
1. **收集数据**：收入、支出、应收应付
2. **建立模型**：按周预测现金流入流出
3. **情景分析**：乐观、中性、悲观
4. **识别缺口**：资金低于安全线的时间点
5. **输出建议**：延迟付款、加快回款、减少库存
6. **滚动更新**：每周更新预测

## 调用关系
**被调用**：CEO Agent、task-planning

**调用**：demand-forecast、purchase-management、cost-analysis

## 依赖工具 / Memory
- Tool: 财务数据、Odoo Accounting
- Memory: 历史现金流、回款周期

## 边界与限制
- 预测基于假设，存在不确定性
- 不替代财务专业判断
- 重大资金决策需 CFO 确认

## 示例
输出：9 月因大促备货将出现 $45,000 资金缺口，建议 8 月压缩非必要支出或申请短期授信
