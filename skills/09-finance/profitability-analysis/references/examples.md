# 利润分析示例

## 示例：SKU 级利润分析

### 输入

SKU：WP-001（宠物智能饮水机）

| 项目 | 金额（美元） |
|------|-------------|
| 售价 | 39.99 |
| 采购成本 | 8.50 |
| 头程物流 | 1.20 |
| FBA 配送费 | 4.52 |
| 平台佣金 15% | 6.00 |
| 广告 Spend | 8.00 |
| 仓储费 | 0.35 |
| 包装费 | 0.50 |
| 退货损失 8% | 3.20 |
| 其他费用 | 0.80 |

### 输出

```markdown
## SKU 利润分析：WP-001

### 利润表
| 项目 | 金额 | 占比 |
|------|------|------|
| 销售收入 | $39.99 | 100.0% |
| 采购成本 | -$8.50 | -21.3% |
| 头程物流 | -$1.20 | -3.0% |
| FBA 配送费 | -$4.52 | -11.3% |
| 平台佣金 | -$6.00 | -15.0% |
| 广告费 | -$8.00 | -20.0% |
| 仓储费 | -$0.35 | -0.9% |
| 包装费 | -$0.50 | -1.3% |
| 退货损失 | -$3.20 | -8.0% |
| 其他费用 | -$0.80 | -2.0% |
| **净利润** | **$6.92** | **17.3%** |

### 成本结构分析
- 最大成本：广告费 20% + 平台佣金 15% + 采购成本 21.3% = 56.3%
- 可变成本占比高，广告优化空间大

### 评级
- 利润率：17.3% → B 级
- 利润健康度：中等偏上

### 优化建议
1. **广告优化**：ACOS 从 40% 降至 30%，可释放 $2.0 利润
2. **降低退货率**：从 8% 降至 5%，可释放 $1.2 利润
3. **采购议价**：量大后压价至 $8.0，可释放 $0.5 利润

### 优化后预测
| 场景 | 净利润 | 利润率 |
|------|--------|--------|
| 当前 | $6.92 | 17.3% |
| 广告优化后 | $8.92 | 22.3% |
| 广告 + 退货 + 采购 | $10.62 | 26.6% |

### 结论
WP-001 当前利润率 17.3%，属于健康 SKU。重点优化广告效率，目标利润率 25%+。
```

## 示例：SKU 利润排行

### 输入

5 个 SKU 的利润数据。

### 输出

```markdown
## SKU 利润排行

| SKU | 月销量 | 收入 | 利润 | 利润率 | 评级 |
|-----|--------|------|------|--------|------|
| WP-003 | 600 | $23,994 | $6,600 | 27.5% | A |
| WP-001 | 450 | $17,996 | $3,114 | 17.3% | B |
| WP-005 | 300 | $11,997 | $1,800 | 15.0% | B |
| WP-002 | 150 | $5,998 | -$450 | -7.5% | D |
| WP-004 | 80 | $3,199 | -$640 | -20.0% | D |

### 建议
- A 级：WP-003 加大广告和库存
- B 级：WP-001、WP-005 优化广告和成本
- D 级：WP-002、WP-004 考虑降价清仓或下架
```
