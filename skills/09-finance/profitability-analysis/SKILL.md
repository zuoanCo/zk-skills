# profitability-analysis · 利润分析

看清每个 SKU 到底赚不赚钱。

## 用途

- 计算 SKU 级真实利润
- 输出 SKU 利润排行
- 识别亏损 SKU 和利润黑马
- 分析成本结构优化空间
- 支撑定价和选品决策

## 触发场景

- 选品阶段测算利润
- 月度利润复盘
- 发现销售额高但利润低
- 调整定价或广告预算前

## 输入

- SKU 销售数据
- 采购成本
- 物流成本（头程 + 尾程）
- 平台佣金和费用
- 广告 spend
- 税费（VAT / GST / 销售税）
- 退货率
- 其他费用（仓储、包装、售后）

## 输出

```markdown
## SKU 利润分析报告

### 利润概览
- 总收入
- 总成本
- 总利润
- 整体利润率

### SKU 利润排行
| SKU | 销量 | 收入 | 总成本 | 利润 | 利润率 | 评级 |
|-----|------|------|--------|------|--------|------|

### 成本结构
### 亏损 SKU 诊断
### 优化建议
```

## 成本构成

```
利润 = 销售额
     - 采购成本
     - 头程物流
     - 平台佣金
     - FBA / 仓储费
     - 广告费
     - 尾程物流
     - 税费
     - 退货损失
     - 包装 / 售后等其他费用
```

## 工作流

1. **收集成本数据**：采购、物流、平台、广告、税费。
2. **按 SKU 归集**：确保每一笔费用对应到 SKU。
3. **计算单位利润**：单件收入 - 单件全成本。
4. **利润分级**：
   - A：高利润高销量
   - B：有利润可优化
   - C：微利或亏损
   - D：持续亏损
5. **输出建议**：提价、降本、停售、加广告。

## 调用关系

**调用**：cost-analysis、tax-analysis、odoo-integration、advertising-analysis

## 依赖工具 / Memory

- Tool: Odoo Accounting / Sales、广告平台报告、物流账单
- Memory: 历史 SKU 利润、成本基准

## 边界与限制

- 数据完整性影响准确性
- 间接费用分摊需约定规则
- 只输出分析，不自动调价或下架

## 示例

输入：某 SKU 上月销售 1000 件，售价 $39.99
输出：单件利润 $6.2，利润率 15.5%，广告占比偏高，建议优化关键词降低 ACOS 后可提升至 18%
