# policy-monitoring · 平台规则监控

## 用途
- 监控平台政策变化
- 预警合规风险
- 及时调整运营策略
- 避免因违规导致处罚

## 触发场景
- 每日/每周政策扫描
- 收到平台通知
- 店铺绩效异常
- 新规则上线

## 输入
- 监控平台列表
- 业务涉及的政策领域
- 历史违规记录

## 输出
```markdown
## 平台规则监控报告

### 新规则摘要
### 影响评估
### 涉及业务
### 建议行动
### 截止时间
```

## 工作流
1. **设置监控范围**：类目、广告、物流、售后
2. **采集政策更新**：平台公告、卖家中心
3. **解读影响**：对当前业务的影响程度
4. **评估风险**：高 / 中 / 低
5. **输出建议**：调整 Listing、广告、流程
6. **跟踪闭环**：确认已落实

## 调用关系
**被调用**：amazon-operation、shopify-operation、tiktok-shop-operation

**调用**：compliance-check、feishu-automation

## 依赖工具 / Memory
- Tool: 平台公告、卖家中心
- Memory: 历史政策变化、处罚案例

## 边界与限制
- 政策解读不替代官方说明
- 重大规则变化需法务/运营确认
- 监控范围受限于公开信息

## 示例
输出：Amazon 更新宠物用品 FDA 合规要求，90 天内需补充检测报告，涉及 3 个 SKU
