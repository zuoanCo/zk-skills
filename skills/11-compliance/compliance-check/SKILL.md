# compliance-check · 产品合规

## 用途
- 识别目标市场合规要求
- 检查认证是否齐全
- 评估产品合规风险
- 输出合规检查清单

## 触发场景
- 选品阶段
- 进入新市场
- 产品变更
- 平台合规审查

## 输入
- 产品信息
- 目标市场
- 现有认证
- 供应商资料

## 输出
```markdown
## 合规检查报告

### 适用法规
### 所需认证
### 现有认证状态
### 缺失项
### 风险等级
### 行动计划
```

## 工作流
1. **确定市场**：美国、欧盟、英国等
2. **识别法规**：FDA、CE、FCC、RoHS、CPC 等
3. **核对认证**：检查证书、测试报告
4. **评估风险**：高 / 中 / 低
5. **输出清单**：缺失项、负责人、时间
6. **跟踪闭环**：认证补齐确认

## 调用关系
**被调用**：product-selection、supplier-search

**调用**：policy-monitoring、supplier-evaluation

## 依赖工具 / Memory
- Tool: 合规数据库、认证文件
- Memory: 各国合规要求、历史问题

## 边界与限制
- 不替代专业合规顾问
- 法规变化需持续更新
- 最终合规责任在人类

## 示例
输出：美国销售宠物饮水机需 FCC（带电）和 FDA 食品接触材料检测，欧盟需 CE 和 RoHS，当前缺失 FDA 报告
