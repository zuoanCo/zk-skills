# trademark-check · 商标检查

## 用途
- 检查品牌名可注册性
- 识别潜在商标侵权
- 监控竞品商标动态
- 保护自有品牌

## 触发场景
- 新品命名
- 品牌注册前
- 收到侵权投诉
- 关键词广告投放前

## 输入
- 品牌名 / 产品名
- 目标市场
- 产品类别
- 待检查关键词

## 输出
```markdown
## 商标检查报告

### 检查对象
### 检索结果
### 冲突风险
### 建议行动
### 注册建议
```

## 工作流
1. **商标局检索**：USPTO、EUIPO、中国商标网等
2. **分类匹配**：核对产品类别
3. **相似度判断**：文字、发音、含义
4. **评估风险**：高 / 中 / 低
5. **输出建议**：改名、注册、监控
6. **持续监控**：新申请商标预警

## 调用关系
**被调用**：product-positioning、amazon-operation

**调用**：policy-monitoring

## 依赖工具 / Memory
- Tool: 商标局数据库、检索工具
- Memory: 自有商标、黑名单

## 边界与限制
- 不替代律师意见
- 检索结果有滞后性
- 最终注册需专业机构

## 示例
输出：品牌名 'FlowPaw' 在美国无相同商标，建议尽快注册；关键词 'Catit' 为竞品商标，需加入否定词
