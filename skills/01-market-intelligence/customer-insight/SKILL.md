# customer-insight · 用户洞察

## 用途
- 从评论、社媒、社区中提炼用户需求
- 识别用户痛点、购买动机、拒绝原因
- 提取情绪关键词和口碑趋势
- 为产品定位、Listing 文案、客服话术提供洞察

## 触发场景
- 新品开发前需要了解用户
- Listing 转化率低，需要优化卖点
- 差评增多，需要分析根因
- 品牌升级或产品迭代前

## 输入
- 评论数据（Amazon、独立站、社媒）
- 社媒讨论（Reddit、TikTok、Instagram）
- 客服对话记录
- 问卷或调研数据

## 输出
```markdown
## 用户洞察报告

### 用户画像
### 核心痛点
### 购买原因
### 拒绝原因
### 情绪关键词
### 未被满足的需求
### 产品改进建议
```

## 工作流
1. **数据采集**：收集评论、社媒、客服记录
2. **数据清洗**：去重、去噪、分类
3. **主题聚类**：痛点、卖点、使用场景
4. **情绪分析**：正面、负面、中性
5. **提炼洞察**：形成可行动结论
6. **输出报告**：结构化呈现

## 调用关系
**被调用**：product-positioning、listing-writing、customer-support

**调用**：market-research、data-analysis

## 依赖工具 / Memory
- Tool: 评论抓取工具、社媒监听工具
- Memory: 用户画像库、历史洞察

## 边界与限制
- 只分析公开可获取数据
- 不窥探用户隐私
- 洞察需结合定量数据验证

## 示例
输入：1000 条 Amazon 评论
输出：痛点 Top 5（噪音 22%、漏水 18%、滤芯贵 15%），改进建议：强调静音、优化密封、推出滤芯订阅
