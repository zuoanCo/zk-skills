# review-management · 评价管理

## 用途
- 分析评价情感和原因
- 生成差评回复话术
- 提取好评关键词
- 监控评分变化

## 触发场景
- 新增差评需要回复
- 月度评价复盘
- 评分下降
- 需要收集好评素材

## 输入
- 产品评价数据
- 星级分布
- 评价内容
- 竞品评价

## 输出
```markdown
## 评价分析报告

### 评分概览
### 好评关键词
### 差评关键词
### 差评回复话术
### 改进建议
```

## 工作流
1. **收集评价**：Amazon、独立站、社媒
2. **情感分类**：好评、中评、差评
3. **关键词提取**：点赞点、吐槽点
4. **生成回复**：差评共情 + 解决，好评感谢
5. **监控趋势**：评分、评论数、星级分布
6. **输出建议**：产品改进、客服优化

## 调用关系
**被调用**：amazon-operation、customer-support

**调用**：complaint-analysis、customer-insight

## 依赖工具 / Memory
- Tool: 评价抓取工具
- Memory: 优秀回复模板、差评根因库

## 边界与限制
- 不删除或修改真实评价
- 不诱导虚假好评
- 回复需符合平台政策

## 示例
输出：差评集中在滤芯难买，建议上架滤芯套装并优化 Listing 说明，同时生成官方回复话术
