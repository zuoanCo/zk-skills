# customer-support · 客服回复

让客服回复专业、快速、有温度。

## 用途

- 回复售前咨询（产品、物流、价格）
- 处理售后问题（使用指导、故障排查）
- 回复投诉和差评
- 生成多语言回复（英文、西班牙语、德语等）
- 总结客服会话中的产品问题

## 触发场景

- 收到客户消息需要回复
- 批量处理同类客诉
- 需要生成差评回复模板
- 客服团队需要回复建议

## 输入

- 客户消息
- 订单信息
- 产品信息
- 物流信息
- 退款 / 退货政策
- 历史沟通记录
- 目标语言

## 输出

```markdown
## 客服回复建议

### 问题分类
### 情绪判断
### 回复要点
### 推荐回复（{语言}）
### 是否需要升级
### 是否需要创建工单
```

## 工作流

1. **意图识别**：咨询 / 投诉 / 售后 / 差评。
2. **情绪判断**：友好 / 不满 / 愤怒。
3. **信息检索**：订单、物流、产品、政策。
4. **生成回复**：
   - 先共情
   - 再解释 / 解决
   - 给明确下一步
5. **多语言输出**：按目标市场语言生成。
6. **标记升级**：涉及退款、安全、法律时标记人工处理。

## 回复原则

- 先理解情绪，再解决问题
- 不承诺无法兑现的方案
- 不自动退款、不退换货
- 涉及产品质量和安全升级给人类
- 语言地道，避免机器感

## 调用关系

**被调用**：task-planning、workflow-automation

**调用**：complaint-analysis、review-management、refund-management、odoo-integration

## 依赖工具 / Memory

- Tool: 电商平台消息接口（如接入）、Odoo Sales
- Memory: FAQ、历史优秀回复、产品问题知识库

## 边界与限制

- 只生成回复建议，不自动发送
- 不自动退款 / 退货 / 重发
- 敏感问题必须人工确认
- 多语言回复需本地化审校

## 示例

输入：客户说饮水机漏水，很失望
输出：安抚 + 排查步骤 + 提供换货或退款选项（需人工确认）+ 英文回复草稿
