# complaint-analysis · 投诉分析

## 用途
- 分类和量化客户投诉
- 提取产品问题根因
- 识别高频服务问题
- 推动产品和流程改进

## 触发场景
- 投诉量上升
- 需要产品改进依据
- 月度客服复盘
- 差评批量分析

## 输入
- 客户投诉记录
- 客服对话
- 退货原因
- 差评内容

## 输出
```markdown
## 投诉分析报告

### 投诉总量与趋势
### 投诉分类
### 高频问题 Top 10
### 产品问题根因
### 改进建议
### 责任部门分配
```

## 工作流
1. **收集投诉**：客服记录、评论、退货
2. **分类标注**：产品、物流、服务、价格
3. **提取关键词**：漏水、噪音、包装破损
4. **量化趋势**：本周 vs 上周 vs 上月
5. **根因分析**：设计、生产、物流、包装
6. **输出改进建议**：责任部门 + 行动项

## 调用关系
**被调用**：customer-support、review-management

**调用**：data-analysis、product-selection

## 依赖工具 / Memory
- Tool: 客服系统、评论数据
- Memory: 历史投诉库、改进措施效果

## 边界与限制
- 保护客户隐私
- 不用于追责个人
- 需结合生产数据验证

## 示例
输出：本月投诉 Top 3 为漏水 35%、噪音 22%、包装破损 15%，建议改进密封圈和包装方案
