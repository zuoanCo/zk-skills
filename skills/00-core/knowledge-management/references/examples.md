# 知识管理示例

## 示例 1：失败案例沉淀

### 输入

某次宠物饮水机广告投放，CPC 从 $0.8 涨到 $2.5，ACOS 从 25% 涨到 55%，一周后才发现原因是误加了竞品品牌词作为广泛匹配。

### 输出知识条目

```markdown
---
type: 经验
domain: advertising
author: advertising-agent
created: 2026-07-15
tags: [ppc, brand-keyword, broad-match, acos]
---

## 场景
Amazon PPC 广告 ACOS 短期内暴涨。

## 现象
CPC 从 $0.8 涨到 $2.5，ACOS 从 25% 涨到 55%。

## 原因
误将竞品品牌词加入自动广告的广泛匹配，导致高价点击。

## 行动
1. 立即将竞品品牌词加入否定词
2. 把自动广告改为只降低或固定出价
3. 每周审查 Search Term Report

## 结果
ACOS 3 天内回落至 28%。

## 可复用建议
- 所有广告 Campaign 上线前必须预设否定词清单
- 品牌词（自己+竞品）纳入关键词管理 SOP
- ACOS 波动 >10pp 时优先检查关键词匹配方式
```

## 示例 2：最佳实践沉淀

### 输入

多次测试发现，宠物饮水机主图用"猫咪正在喝水 + 水流可视化"比单纯产品白底图 CTR 高 35%。

### 输出知识条目

```markdown
---
type: 经验
domain: listing
created: 2026-07-20
tags: [image, ctr, main-image, pet]
---

## 场景
宠物饮水机主图 A/B 测试。

## 现象
"猫咪喝水 + 水流"主图 CTR 比白底图高 35%。

## 原因
消费者需要瞬间理解产品使用场景和效果。

## 可复用建议
- 宠物用品主图优先展示动物使用场景
- 液体/流动类产品突出动态效果
- 首图避免纯产品白底，除非产品本身极具设计感
```
