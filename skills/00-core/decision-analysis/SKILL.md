# decision-analysis · 决策分析

把复杂商业决策结构化、量化、可比较。避免拍脑袋。

## 用途

- 做 SWOT 分析
- 做成本收益分析（Cost-Benefit Analysis）
- 做风险分析（概率 × 影响）
- 多方案打分比较
- 输出决策建议与置信度

## 触发场景

- 选品决策需要量化比较
- 供应商选择、渠道选择
- 新市场进入决策
- 投资决策或预算分配
- CEO Agent 需要做最终决策

## 输入

- 决策问题
- 可选方案（2-5 个）
- 评估维度与权重
- 各方案数据（成本、收益、风险、时间）
- 风险偏好（保守 / 中性 / 激进）

## 输出

```markdown
## 决策分析：{问题}

### 方案概览
| 方案 | 预期收益 | 预期成本 | 净收益 | 风险等级 | 得分 |
|------|---------|---------|--------|---------|------|
| A    | ...     | ...     | ...    | 中      | 82   |
| B    | ...     | ...     | ...    | 高      | 75   |

### SWOT 分析（推荐方案）
- Strengths
- Weaknesses
- Opportunities
- Threats

### 风险矩阵
| 风险 | 概率 | 影响 | 应对措施 |

### 决策建议
推荐方案 X，理由...
置信度：75%
```

## 工作流

1. **明确决策问题**：避免伪问题。
2. **列出方案**：穷尽主要可行方案。
3. **定义评估维度**：收益、成本、风险、战略契合度等。
4. **收集数据**：调用 market-research、profitability-analysis 等 Skill 补充数据。
5. **量化评分**：加权打分。
6. **风险分析**：列出关键风险与应对。
7. **输出建议**：给出推荐方案、备选方案、触发条件。

## 调用关系

**被调用**：CEO Agent、task-planning

**调用**：market-research、competitor-analysis、profitability-analysis、cost-analysis

## 依赖工具 / Memory

- Memory: 历史决策结果、行业基准数据
- Tool: 电子表格 / 飞书文档（输出报告）

## 边界与限制

- 只提供分析建议，不替人类做最终决策
- 数据质量决定分析质量
- 对高度不确定的市场，需标注置信度

## 示例

输入：美国宠物饮水机 vs 宠物摄像头，选哪个？

输出：多方案比较表 + SWOT + 推荐宠物饮水机（市场更成熟、竞争可控、利润率 35%）
