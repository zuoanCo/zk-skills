# report-generation · 报告生成

把零散的数据和结论，变成人类可读、可传播、可归档的商业报告。

## 用途

- 生成周报 / 月报
- 生成商业计划书
- 生成市场调研报告
- 生成会议纪要 / 决策纪要
- 生成飞书文档或 Markdown

## 触发场景

- 每周 / 每月需要向管理层汇报
- 完成一次市场调研或竞品分析后
- 需要对外输出商业计划
- 重要会议后需要输出纪要

## 输入

- 报告类型
- 原始数据 / 分析结论 / 任务进展
- 目标读者
- 篇幅要求
- 模板要求（可选）

## 输出

- Markdown 文件
- PDF（可选，通过工具生成）
- 飞书文档（可选，通过 feishu-automation）

## 工作流

1. **确认报告目标**：读者、用途、关键信息。
2. **收集素材**：从相关 Skill / Memory / 数据库拉取数据。
3. **结构设计**：按报告类型选择结构（执行摘要 → 正文 → 结论 → 行动项）。
4. **内容生成**：将数据转化为叙述性文字和图表。
5. **审校润色**：检查逻辑、一致性、可读性。
6. **格式输出**：按指定格式交付。

## 报告模板

### 周报
```markdown
# 电商业务周报

## 本周关键指标
- GMV
- 利润
- 广告 ROAS
- 库存周转

## 本周主要进展
## 下周计划
## 风险与阻塞
```

### 调研报告
```markdown
# {市场} {品类} 调研报告

## 执行摘要
## 市场规模与趋势
## 竞争格局
## 消费者洞察
## 机会与风险
## 建议行动
```

## 调用关系

**被调用**：task-planning、CEO Agent、meeting-summary

**调用**：business-dashboard、data-analysis、feishu-automation

## 依赖工具 / Memory

- Memory: 历史报告、品牌话术库
- Tool: 飞书文档 API、PDF 生成工具

## 边界与限制

- 不编造数据，只基于输入和已验证来源
- 复杂报告需要人类审校后再发布
- PDF 生成依赖外部工具

## 示例

输入：基于本周销售数据生成周报
输出：Markdown 周报 + 关键指标表格 + 下周行动项
