# supplier-search · 供应商搜索

找到靠谱的源头工厂和贸易商。

## 用途

- 根据产品需求搜索潜在供应商
- 筛选工厂实力、MOQ、认证、交期
- 输出候选供应商清单和联系方式
- 为供应商评估和报价分析做准备

## 触发场景

- 选品通过后寻找供应链
- 现有供应商产能不足需要备选
- 新产品开发需要找工厂
- 采购策略调整（成本优化、质量升级）

## 输入

- 产品名称 / 关键词
- 目标材质 / 规格 / 功能要求
- 目标采购量 / 首单 MOQ
- 认证要求（FDA / CE / FCC / RoHS 等）
- 目标交期

## 输出

```markdown
## 供应商搜索报告：{产品}

### 候选供应商
| 序号 | 平台 | 公司名称 | 类型 | MOQ | 认证 | 交期 | 评分 | 链接 |
|------|------|---------|------|-----|------|------|------|------|
| 1    | 1688 | XX 电子 | 工厂 | 500 | CE   | 25天 | 85   | ...  |

### 筛选标准
### 重点关注
### 下一步行动
```

## 工作流

1. **明确需求**：产品、规格、数量、认证、交期。
2. **多平台搜索**：
   - 1688：国内工厂、价格敏感
   - Alibaba：外贸工厂、认证较全
   - Made-in-China / 环球资源：B2B 工厂
3. **初筛过滤**：
   - 工厂 / 贸易商标识
   - 年限、员工数、厂房面积
   - 认证、交易等级、响应率
   - MOQ 与目标匹配度
4. **整理清单**：输出 Top 5-10 候选。
5. **标记风险**：新工厂、认证缺失、交期过长等。

## 调用关系

**被调用**：task-planning、product-selection

**调用**：supplier-evaluation、quotation-analysis、negotiation、compliance-check

## 依赖工具 / Memory

- Tool: 浏览器访问 1688 / Alibaba、API（如有）
- Memory: 已合作供应商、黑名单、历史询价记录

## 边界与限制

- 只搜索公开信息，不侵入平台
- 搜索结果需人工二次验证
- 联系方式和报价可能变化，需实时确认

## 示例

输入：宠物智能饮水机，首单 500 台，需 CE/FCC
输出：5 家候选工厂，2 家认证齐全，1 家交期仅 20 天，推荐优先联系
