# 供应商搜索示例

## 示例：宠物智能饮水机供应商搜索

### 输入

- 产品：宠物智能饮水机（不锈钢款）

- 认证要求：CE、FCC、FDA 食品接触材料
- 目标交期：≤30 天
- 目标采购价：≤$9.0

## 示例：供应商初筛检查清单

```markdown
### 供应商初筛检查清单

- [ ] 公司类型：工厂 / 贸易
- [ ] 成立年限 ≥ 3 年
- [ ] 员工数 / 厂房面积
- [ ] 认证齐全（FDA/CE/FCC/RoHS）
- [ ] MOQ 与首单匹配
- [ ] 交期 ≤ 30 天
- [ ] 1688 / Alibaba 交易等级
- [ ] 响应速度（24 小时内回复）
- [ ] 是否支持 OEM/ODM
- [ ] 是否提供样品
- [ ] 付款方式（30% 定金 + 70% 出货前）
```
