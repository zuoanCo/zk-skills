# supplier-evaluation · 供应商评估

## 用途
- 建立供应商评估体系
- 对候选供应商量化打分
- 识别供应商风险
- 输出合作等级和建议

## 触发场景
- 新供应商入围评估
- 年度供应商考核
- 出现质量问题后复评
- 需要开发备选供应商

## 输入
- 供应商基本信息
- 报价和历史成交
- 样品质量报告
- 验厂报告
- 客户反馈

## 输出
```markdown
## 供应商评估报告

### 评分表
| 维度 | 权重 | 得分 | 说明 |

### 综合评级
### 风险分析
### 合作建议
```

## 工作流
1. **信息收集**：资质、产能、认证、财务
2. **多维度评分**：价格、质量、响应、产能、风险
3. **现场/视频验厂**：生产能力、品控
4. **样品测试**：质量、功能、包装
5. **综合评级**：A/B/C/D
6. **输出建议**：主力 / 备选 / 淘汰

## 调用关系
**被调用**：supplier-search、quotation-analysis

**调用**：compliance-check、knowledge-management

## 依赖工具 / Memory
- Tool: 验厂清单、样品测试表
- Memory: 供应商档案、历史评分

## 边界与限制
- 评估基于可验证信息
- 不替代实地考察（重要供应商）
- 评估结果需定期更新

## 示例
输出：工厂 B 综合评分 86（A 级），建议作为主力供应商；工厂 C 质量风险高，列为备选
