# quotation-analysis · 报价分析

把供应商报价算清楚，找到性价比最优解。

## 用途

- 比较多个供应商报价
- 拆解报价中的隐藏成本
- 评估 FOB、EXW、CIF 等贸易条款
- 计算到岸成本和单位成本
- 输出采购建议和议价空间

## 触发场景

- 收到多家供应商报价后
- 需要判断哪个供应商更划算
- 采购成本异常，需要重新核算
- 年度采购谈判前准备

## 输入

- 多份供应商报价单
- 产品规格 / BOM
- 采购数量
- 贸易条款
- 物流方式（海运 / 空运 / 快递）
- 目标利润率

## 输出

```markdown

### 报价对比表
| 供应商 | 单价 | MOQ | 包装费 | 认证费 | 模具费 | 运费 | 关税 | 到岸单价 | 总价 |
|--------|------|-----|--------|--------|--------|------|------|---------|------|

### 成本结构拆解
### 隐藏成本提示
### 采购建议
- 推荐供应商：XX
- 理由：...
- 议价空间：...

### 风险提示
```

## 工作流

1. **标准化报价**：统一货币、单位、贸易条款。
2. **拆解成本**：产品单价、包装、认证、模具、运费、保险、关税、杂费。
3. **计算到岸成本**：按不同贸易条款换算。
4. **质量 / 交期加权**：不只看价格。
5. **识别隐藏成本**：认证费分摊、模具费、售后成本。
6. **输出建议**：推荐供应商 + 备选 + 议价策略。

## 调用关系

**被调用**：task-planning、supplier-search、purchase-management

**调用**：supplier-evaluation、logistics-optimization、cost-analysis

## 依赖工具 / Memory

- Tool: 汇率换算、物流费用参考表、关税查询
- Memory: 历史成交价、供应商报价库

## 边界与限制

- 报价以供应商最新确认为准
- 不自动接受任何报价
- 大宗采购需法律和财务复核合同

## 示例

输入：3 家工厂报价宠物饮水机
输出：A 单价低但认证费高，B 单价高但含认证且交期短，推荐 B，可议价 8%
