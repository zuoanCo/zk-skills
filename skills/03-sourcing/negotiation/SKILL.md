# negotiation · 供应商谈判

## 用途
- 生成询价和议价话术
- 制定降价策略和让步方案
- 起草合同关键条款
- 模拟谈判场景

## 触发场景
- 收到报价后需要议价
- 年度合同谈判
- 要求更优付款条件
- 处理交期或质量问题

## 输入
- 供应商报价
- 目标价格
- 历史合作情况
- 市场行情
- 谈判底线

## 输出
```markdown
## 谈判方案

### 目标与底线
### 议价话术
### 让步策略
### 合同条款建议
### 风险点提示
```

## 工作流
1. **分析报价**：识别水分和合理性
2. **设定目标价和底线价**
3. **准备话术**：开场、压价、收尾
4. **设计让步**：阶梯式让步，每次让步换条件
5. **合同条款**：付款、交期、质量、售后
6. **模拟演练**：预判供应商反应

## 调用关系
**被调用**：supplier-search、quotation-analysis

**调用**：supplier-evaluation、knowledge-management

## 依赖工具 / Memory
- Memory: 历史谈判案例、行业成本基准
- Tool: 报价分析表

## 边界与限制
- 只生成建议，不直接发送给供应商
- 重大合同条款需法务确认
- 不采取欺诈或胁迫手段

## 示例
输出：目标降价 8%，话术强调量大和长期合作，让步方案为接受 5% 降幅换 30 天账期
