# conversion-analysis · 转化分析

## 用途
- 分析广告到购买的转化漏斗
- 识别 CTR、CVR 异常
- 诊断落地页问题
- 输出转化优化建议

## 触发场景
- 广告流量高但销量低
- CTR 或 CVR 异常
- 需要优化落地页
- 大促复盘

## 输入
- 广告数据
- 网站/店铺数据
- 用户行为数据
- 销售数据

## 输出
```markdown
## 转化分析报告

### 漏斗分析
### 关键指标
### 泄漏点识别
### 优化建议
### 预期提升
```

## 工作流
1. **建立漏斗**：曝光 → 点击 → 加购 → 结算 → 购买
2. **计算指标**：CTR、CVR、CPA、ROAS、AOV
3. **对比基准**：行业、历史、竞品
4. **识别泄漏点**：哪个环节流失最多
5. **根因分析**：素材、价格、页面、流程
6. **输出建议**：针对性优化

## 调用关系
**被调用**：advertising-analysis、amazon-operation、shopify-operation

**调用**：data-analysis、creative-testing

## 依赖工具 / Memory
- Tool: GA4、广告平台、热图工具
- Memory: 行业转化率基准

## 边界与限制
- 归因分析存在局限性
- 不承诺具体提升幅度
- 需结合多数据源判断

## 示例
输出：点击到加购转化率 5%（健康），但加购到结算仅 20%（偏低），建议优化结算页运费显示
