# creative-testing · 素材测试

## 用途
- 设计素材 A/B 测试
- 分析 CTR、CVR、ROAS 差异
- 识别最佳创意方向
- 沉淀高转化素材模板

## 触发场景
- 广告 CTR 低
- 需要新素材方向
- 大促前测试创意
- 素材疲劳需要更新

## 输入
- 现有素材数据
- 竞品素材
- 测试预算
- 目标受众
- 产品卖点

## 输出
```markdown
## 素材测试方案

### 测试假设
### 素材版本
### 测试预算与周期
### 分组策略
### 胜出标准
### 测试结果分析
```

## 工作流
1. **提出假设**：某类图片/视频更吸引目标用户
2. **设计版本**：主图、场景、人物、文案
3. **分配预算**：控制变量，确保统计显著
4. **运行测试**：通常 7-14 天
5. **分析结果**：CTR、CVR、ROAS、CPA
6. **沉淀模板**：获胜素材扩展为系列

## 调用关系
**被调用**：campaign-management、amazon-operation

**调用**：image-prompt、video-script、conversion-analysis

## 依赖工具 / Memory
- Tool: 广告平台 A/B 测试功能
- Memory: 历史测试结果、高转化素材模板

## 边界与限制
- 测试需有足够样本量
- 不基于短期数据做决策
- 创意需符合品牌规范

## 示例
输出：测试 3 组主图，'猫咪喝水场景图' CTR 1.8% 胜出（vs 白底图 0.9%），建议扩展为视频素材
