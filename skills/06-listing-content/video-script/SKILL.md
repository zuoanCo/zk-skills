# video-script · 短视频脚本

## 用途
- 生成 TikTok 短视频脚本
- 生成 Amazon 主图视频脚本
- 生成广告视频脚本
- 提高内容转化率

## 触发场景
- 需要拍摄 TikTok 视频
- 新品需要主图视频
- 广告投放需要视频素材
- 短视频表现差需要重写

## 输入
- 产品信息
- 目标平台
- 目标用户
- 核心卖点
- 视频时长
- 风格要求

## 输出
```markdown
## 短视频脚本

### 视频信息
### 镜头 1：开场（0-3s）
### 镜头 2：痛点（3-8s）
### 镜头 3：产品介绍（8-20s）
### 镜头 4：使用场景（20-30s）
### 镜头 5：CTA（30-35s）
### 字幕 / 音乐建议
```

## 工作流
1. **确定目标**：品牌曝光、转化、教育
2. **研究爆款**：分析同类高赞视频
3. **设计钩子**：前 3 秒抓住注意力
4. **展示卖点**：功能 → 收益 → 情绪
5. **设计 CTA**：购买、关注、评论
6. **输出分镜**：画面、台词、时长、音乐

## 调用关系
**被调用**：tiktok-shop-operation、amazon-operation、creative-testing

**调用**：customer-insight、competitor-analysis

## 依赖工具 / Memory
- Tool: 视频分析工具
- Memory: 爆款脚本模板、品牌话术库

## 边界与限制
- 不夸大产品功能
- 遵守平台内容规范
- 音乐、字体需注意版权

## 示例
输出：15 秒 TikTok 脚本，前 3 秒猫咪拒绝喝旧水，中间展示饮水机水流，结尾主人微笑 + 'Link in bio'
