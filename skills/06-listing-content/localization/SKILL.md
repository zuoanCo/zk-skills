# localization · 本地化

## 用途
- 翻译并本地化 Listing 文案
- 适配不同市场的文化表达
- 避免直译和语言错误
- 提升本地用户信任感

## 触发场景
- 产品进入新市场
- 多平台多语言上架
- 广告文案需要本地化
- 客服模板需要多语言版本

## 输入
- 原始文案
- 源语言
- 目标市场
- 目标平台
- 品牌调性

## 输出
```markdown
## 本地化方案

### 翻译文本
### 文化适配说明
### 禁用词 / 敏感词检查
### 本地市场表达建议
```

## 工作流
1. **直译**：准确传达原意
2. **文化适配**：俚语、节日、度量衡、消费习惯
3. **平台适配**：Amazon、Shopify、TikTok 表达差异
4. **本地审校**：检查语法、语气、文化禁忌
5. **A/B 测试**：不同版本对比
6. **输出最终文案**

## 调用关系
**被调用**：listing-writing、customer-support、advertising-analysis

**调用**：market-research

## 依赖工具 / Memory
- Tool: 翻译工具、本地审校
- Memory: 本地化术语库、文化禁忌

## 边界与限制
- 不编造本地化信息
- 宗教、政治、文化敏感内容需人工复核
- 法律声明需本地法务确认

## 示例
输出：美国版 'faucet' 在英国用 'tap'；德国市场需强调环保和认证；日本市场语气需更礼貌
