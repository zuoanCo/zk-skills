# 德州学院逐梦商学院 · 公众号文章创作

把「主题/素材 → 一篇可直接交给新媒体中心排版的公众号推文」这件事标准化。核心目标是：**固定元素一个字不改、一种格式不变、一个称呼不错，可变内容按题材模板填充，图片视频逐项确认**。

## 何时使用

- 用户说"给逐梦商学院写篇推送""商学院公众号文章""商小蓝新媒体中心推文"。
- 用户给了活动通知、安全教育、节日致敬、社会实践、招新报名等素材，需要成稿。
- 用户已有初稿，需要润色成符合商学院公众号风格的版本。

## 不适用

- 其他学院/其他学校的公众号（风格、署名、审校链不同）。
- 纯学术论文、课程论文、毕业设计。
- 与学校宣传口径无关的商业广告或外部投稿。

## 账号定位与语气

- **账号名**：逐梦商学院
- **运营主体**：商学院商小蓝新媒体中心（招新/学生会类由商学院学生会运营时改为相应署名）。
- **拟人 IP**：「商小蓝」是账号对外发声的亲切形象，可用于邀请、提醒、互动场景。
- **语气**：正式但不生硬，温暖但有分寸。面向学生时像老师/学长姐叮嘱；面向活动报道时客观、详实、有高度；节日致敬类庄重大气。
- **人称**：多用"同学们""全体同学""202X级新生"；涉及家校联动时可用"家长""家校"。

### 1.2 篇尾固定块（顺序、符号、空格完全一致）

每篇文章末尾必须按以下顺序出现，且格式一致：

```
往期推荐

[文章标题1]

[文章标题2]

[文章标题3]

END

/ 商 学 院 商 小 蓝 新 媒 体 中 心 /
          文字来源｜[来源名称]
  编 辑｜[姓名]    
      校 对｜[姓名]    
初 审｜[姓名]   
二 审｜刘金亮
终 审｜孙晨晨

为商学院点赞和在看!
```

学生会版本：

```
/ 商 学 院 学 生 会 /
编 辑｜[姓名]
校 对｜[姓名]
  初 审｜[姓名]   
二 审｜刘金亮
终 审｜孙晨晨

为商学院点赞和在看!
```

**不可变规则**：
- 二 审｜刘金亮、终 审｜孙晨晨 任何情况下不可改动。
- `/ 商 学 院 商 小 蓝 新 媒 体 中 心 /` 中每个汉字之间必须有一个全角空格。
- `往期推荐` 后面必须空一行，然后列出恰好 3 条往期文章标题，每条标题独占一行，标题之间空一行。
- `END` 必须大写、独占一行、位于署名区上方。
- 署名区的竖线分隔符必须是全角 `｜`，角色名后留适当全角空格以对齐。
- 互动语固定为 `为商学院点赞和在看!`，感叹号，不可改为"点赞在看""点在看"等。

### 1.3 往期推荐默认占位

如无用户提供的最新 3 篇往期文章，默认使用：

```

春和景明，和商小蓝一起赴一场春日之约吧！
```

### 1.4 图片声明固定句式

若正文配图使用 AI 生成，必须在 `END` 之前、正文最后一段之后单独加一行：

```
注：图片由AI技术生成
```

### 1.5 来源标注固定格式

- 文字来源：`文字来源｜德州学院保卫处`
- 图片来源：`图 片｜央视新闻`
- 文字作者：`文 字｜张凡`

### 1.6 编号与符号固定格式

- 分条编号统一使用两位阿拉伯数字：`01`、`02`、`03`……不可使用 `1.`、`（一）`、`一、`、`第1条` 等。
- 两位数字独占一行，下方空一行，再写小标题。
- 小标题后加冒号或不加冒号需与题材模板一致：
  - 安全提醒类：不加冒号，格式为「对仗短句」
  - 活动报道类：加冒号，格式为「四字模块名：模块副标题」
- 活动报道总结段前使用符号 `❖`（黑色菱形）作为段落起始标记，独占一行，后空一行再接正文。

## 四、排版格式规范

### 4.1 文字样式

- 正文字号：17px
- 字体：system-ui, -apple-system, BlinkMacSystemFont, Arial, sans-serif
- 行间距：适中，段落间空一行
- 对齐：正文两端对齐（text-align: justify）
- 颜色：正文 rgba(0, 0, 0, 0.9)，小标题/注释可用 #888888

### 4.2 段落节奏

- 一段不超过 3-4 行。
- 关键句、口号句、升华句单独成段。
- 节日致敬/招新开场常用"一句一行"的诗意排比。

### 4.3 小标题格式

- 安全提醒类：对仗短句，8-14 字，如「行程报备常态化，行踪透明保安心」。
- 活动报道类：`四字模块名：模块副标题`，如「双育并行：体育实训+心理团辅多学科协同育人」。
- 招新报名类：简明模块名，如「选拔对象」「选拔要求」「工作职责」「选拔流程」。

### 4.4 列表格式

- 招新报名类的"选拔要求""工作职责"使用阿拉伯数字加点：
  ```
  1. 选拔对象中，党员学生干部优先；
  2. 拥有良好语言表达能力，善于团队沟通协作；
  ```
- 流程说明使用中文序号：
  ```
  （一）填写报名表
  （二）加入选拔群聊
  （三）线上面试
  （四）面试时间
  ```

### 4.5 禁止使用的变体

- 不可将「二 审」写成「二审」「复审」「二审老师」。
- 不可将「终 审」写成「终审」「最终审核」「审核」。
- 不可将「为商学院点赞和在看!」改为「点赞+在看」「点在看」「一键三连」。
- 不可将 `01/02/03` 改为 `1./2./3.` 或 `一、二、三`。
- 不可省略 `END` 标记或将其改为「结束」「完」。
- 不可将「往期推荐」改为「相关阅读」「更多精彩」。
- 不可将「商小蓝」改为「商学院」「小蓝」或其他昵称。

## 五、题材主题与结构模板

### A. 安全提醒/通知类

**典型标题**：暑假外出守安全，十条叮嘱记心间
**结构**：
1. 背景段：说明时间、场景、风险。
2. 总起段：学校结合大学生特点梳理 N 条细则，请全体同学牢记。
3. 分条正文：用 `01/02/03…` 编号，每条格式为：
   - 小标题（对仗、8-14 字）
   - 展开说明（1-2 段，具体、可操作、有禁止性用语）
4. 结尾段：总结+呼吁。
5. 往期推荐 → END → 署名区 → 互动语。

**字数**：1500-2500 字。

### B. 节日/思政致敬类

**典型标题**：今天八一，致敬我们最可爱的人！
**结构**：
1. 诗意排比开场（3-6 句短句，一句一行）。
2. 点题句：今日 XX 节 / 致敬 XX 周年。
3. 升华句：1-3 组对仗/排比，表达敬意。
4. 往期推荐 → END → 署名区 → 互动语。

**字数**：200-600 字。

### C. 活动报道/社会实践类

**典型标题**：2026暑期三下乡（八）｜体育赋能强体魄 心理护航伴成长——德州学院商学院联合金乡县教育和体育局开展留守儿童关爱成长营
**结构**：
1. 导语段：时间、地点、主办单位、参与人员、覆盖对象。
2. 副标题/主题句：用一句话概括活动意义。
3. 分模块报道：用 `01/02/03…` 编号，每模块格式：
   - 模块名（4 字）+ 冒号
   - 模块副标题
   - 具体做法与成效
4. 收尾段：`❖` 符号 + 活动意义 + 下一步计划（一句一行或短段落）。
5. 往期推荐 → END → 署名区 → 互动语。

**字数**：800-1500 字。

### D. 招新/报名通知类

**典型标题**：以陪伴温暖新程，用热忱助力成长 —— 新生班助期待你的加入
**结构**：
1. 开场诗/目的段：诗意短句（3-6 句）+ 选拔目的。
2. 分模块说明：用 `01/02/03/04…` 编号：
   - 01 选拔对象
   - 02 选拔要求
   - 03 工作职责
   - 04 选拔流程
3. 结尾段：欢迎报名 / 期待加入。
4. 往期推荐 → END → 署名区 → 互动语。

**字数**：600-1200 字。

## 六、写作风格细则

1. **短句优先**：一段话不超过 3 行，关键句单独成段。
2. **对仗小标题**：安全/活动/招新类的小标题要求上下句字数相等或接近。
3. **编号规范**：统一用 `01/02/03…` 两位数字，不用其他编号形式。
4. **禁止口语**：不使用「啦」「呢」「吧」「贼」「狠狠」「破防」等网络/口语词。
5. **单位名称完整**：首次出现用全称，如「德州学院商学院」「金乡县教育和体育局」。
6. **家校/校地联动**：安全类强调「家校联动」；实践类强调「校地合作」「三方协同」。
7. **升华自然**：结尾不喊口号，用「希望……」「下一步……」「让……」等句式递进。
8. **商小蓝使用**：仅在邀请、互动、往期推荐标题中使用，正文正式段不使用。

## 九、常见错误

- **改动固定署名**：二 审/终 审人员不可替换为其他人。
- **漏掉 END 标记**：END 必须单独一行，位于往期推荐之后、署名区之前。
- **往期推荐数量不对**：固定 3 条，不能多不能少。
- **图片未声明来源**：使用网络图/新闻图必须标注「图片｜XXX」。
- **AI 图未声明**：AI 生成图必须加「注：图片由AI技术生成」。
- **编号不统一**：同一篇文章里混用 01/02 和 一、二、三。
- **称呼错乱**：将「商小蓝」用于正式正文，或将「同学们」写成「亲们」。

## 十、执行流程

1. **确认题材**：让用户明确是安全提醒 / 节日致敬 / 活动报道 / 招新报名 / 其他。
2. **收集素材**：时间、地点、人物、数据、目的、注意事项、照片/视频/二维码。
3. **选择模板**：按上述 A/B/C/D 模板搭建结构。
4. **生成正文**：保留固定元素，填充可变内容。
5. **应用校验清单**：逐条核对固定格式、称呼、署名、图片声明。
6. **确认素材清单**：按图片与视频确认清单逐项向用户确认。
7. **输出定稿**：生成可直接用于排版的完整推文文本。
